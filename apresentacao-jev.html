O resumo para quem tem dois minutos

O que é

Um modelo de IA que não escreve nem conversa: só decide. Recebe um texto, escolhe entre opções que nós definimos e diz o quanto tem certeza. Em 70 a 500 milissegundos.

Onde ajuda a gente

Onde chega texto livre em volume e alguém precisa decidir para onde mandar: respostas dos disparos de WhatsApp, comentários nos anúncios, revisão de mensagens antes de enviar.

Onde não ajuda

Onde já temos regra fixa (o score A/B/C/D do quiz), onde é preciso escrever (copy, roteiro, resposta ao lead) ou explicar o porquê de uma decisão.

A recomendação

Piloto de 2 semanas na triagem das respostas dos disparos do ZapFlow. Só liga de verdade se concordar com a classificação humana em 90% ou mais.

03 / 12

O que é o Jev

Uma IA feita para máquinas, não para conversas

Lançado em setembro de 2026 pela TypeSafe AI, é o primeiro modelo público de uma categoria nova: os System One Models. Em vez de gerar texto palavra por palavra, ele lê tudo de uma vez e devolve a decisão pronta, num formato que o sistema entende direto.

escolha

Escolhe uma opção

"Esta mensagem é: interessado, dúvida de preço, opt-out ou reclamação?"

nota

Dá uma nota

"De 0 a 10, o quanto este comentário parece um cliente com caso real?"

probabilidade

Diz se é verdade

"Qual a chance de esta mensagem prometer resultado de processo?"

Toda resposta vem com um grau de confiança. É isso que permite a regra "se tiver menos de 80% de certeza, manda para um humano".

04 / 12

A ideia por trás

Pensar rápido e pensar devagar

A ideia vem da psicologia (Kahneman): o "sistema 1" é a decisão rápida e automática; o "sistema 2" é o raciocínio lento. O argumento da TypeSafe é que a maior parte das decisões dentro de um software é do tipo rápido — e estamos pagando preço de raciocínio lento por elas.

Sistema 2 · Claude, GPT

Raciocina e escreve

  • Escreve copy, roteiro, resposta ao lead
  • Resume, analisa, explica o porquê
  • Segundos por resposta
  • Custo por chamada relevante em volume
Sistema 1 · Jev

Decide e segue

  • Classifica, pontua, roteia
  • Não escreve e não explica
  • 70 a 500 milissegundos
  • Custo quase zero, mesmo em milhares de chamadas

Os dois se complementam: o Jev faz a triagem em tempo real, e o Claude entra só quando é preciso escrever ou pensar.

Como funciona na prática

Uma chamada, uma decisão

A integração é uma requisição HTTP: mandamos o texto e o formato da resposta que aceitamos. No ZapFlow isso cabe num nó de "Requisição HTTP", seguido de um "Switch" que manda cada resposta para um caminho.

// o que o ZapFlow manda
POST /v1/decide
{
  "input": "quanto fica a imersão? já tinha comprado o guia",
  "schema": {
    "intencao": {
      "choice": ["quer_comprar", "duvida_preco",
                 "ja_comprou", "opt_out",
                 "suporte", "outro"]
    }
  }
}
// o que volta, em ~0,2 s
{
  "intencao": "duvida_preco",
  "score": 0.91,
  "confidence": 0.95
}

// e o fluxo decide:
// confiança ≥ 0,80 → segue o caminho
// abaixo disso     → vai para um humano

10 / 12

Antes de usar

Os cuidados, do mais sério ao mais leve

Dados pessoais e sigilo

Mandar mensagem de lead para um terceiro exige base legal na LGPD. No escritório pesa também o sigilo profissional do advogado: o relato do caso é informação sensível.

Como mitigar: mandar só o texto da mensagem, sem nome, telefone ou CPF. Não usar no relato de caso do escritório até ter o contrato de tratamento de dados.

Português não é garantido

O site lista inglês, chinês, russo, japonês, coreano, alemão e espanhol. Português não aparece.

Como mitigar: o piloto existe para isso — 200 mensagens reais, conferidas por gente, antes de qualquer automação.

Produto em acesso antecipado

Lançado este mês. Preço, limites e disponibilidade podem mudar, e a empresa é nova.

Como mitigar: nenhum fluxo crítico depende só dele. Se o Jev cair, a mensagem vai para a fila humana, como hoje.

Números do próprio fabricante

Os 194× mais rápido e 445× mais barato são medições internas. O acerto em tarefas reais de outras empresas ainda é pouco documentado.

Como mitigar: medir o nosso acerto, nos nossos dados, e decidir por ele.

Não explica a decisão

Ele devolve a escolha e a confiança, mas não o porquê. Numa decisão errada, não há raciocínio para auditar.

Como mitigar: usar só onde errar é barato (uma mensagem que vai para o lugar errado e volta), nunca onde a decisão precisa de justificativa.

Contexto limitado

Aceita até 64 mil tokens por chamada — muito para uma mensagem, pouco para uma conversa longa inteira.

Como mitigar: mandar a última mensagem e um resumo curto do contexto, não o histórico todo.
